# Bundled asset status

The desktop package includes artwork from `assets/aiv/`, including the 2D skins
and the isometric sprite catalogue used by the 2.5D Castle view.

The repository does not currently record the original source, author, license,
or redistribution permission for each asset set. This file therefore does not
claim that the files are licensed for redistribution.

Before publishing source or binaries, a maintainer should document for each
asset set:

1. its original source and author;
2. whether it is original work, redistributed material, or a derived work;
3. the applicable license or explicit permission; and
4. any attribution or distribution conditions.

If permission cannot be established, replace the affected files with original
or appropriately licensed artwork before distribution.
