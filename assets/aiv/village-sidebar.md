# Village editor sidebar

`village-sidebar.png` is picture 185 (zero-based), 256 x 768 pixels, decoded
from the original Village Editor's `gm/village_interface.gm1`. It supplies
the familiar castle scene behind the Building Categories sidebar. Original
Stronghold artwork is by Firefly Studios.

Category button colors in `src/js/castle-palette.js` follow the existing
village item artwork in `skins/`: bad things 176/177, good things 166/169,
food 74/75, industry 51/52, military 65/88, weapons 82/83, town 95,
castle 86/87, gatehouses 144/145, moat 106, walls 25, towers 110/112,
and Keep 61. Stairs use the stone family. Units and Pause use neutral gray
because they have no single building category fill.
