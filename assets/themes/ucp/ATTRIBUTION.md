# UCP theme

The control, sword checkbox, ornament and parchment PNGs in `textures/` were
created by **Monsterfish** for the UCP GUI. The project owner confirmed that
these assets are intended for this kind of UI reuse and granted permission to
include them in AI Toolkit (22 September 2026).

Source: `UCP3-GUI/src/assets/ucp3/`. These are editor UI assets, not files from
the GUI's separate `game-assets` directory. Original image bytes are preserved.
The corrected `scroll_bar_bottom_hook.png` comes from the UCP website's
`UnofficialCrusaderPatch.github.io/assets/ucp3/` collection by the same designer.
No game sprites or third-party fonts are included by this theme.

The pack manifest preserves attribution alongside the artwork so that copying
the pack folder also preserves this information.
