# AI Toolkit application icon

`assets/icon.png` is the transparent master. `assets/icon.ico` contains
16, 24, 32, 48, 64, 128 and 256-pixel Windows variants. The executable,
BrowserWindow and desktop shortcut use this icon. The Windows application
model ID matches the packaged application ID.

The design modernizes the original Village Editor's compact ivory AI monogram
and horizontal foundation: a castle-shaped A, dark teal badge and amber base.
The reference was extracted from the user's backed-up Gremium `village.exe`,
icon group 101. The legacy executable/icon is not redistributed here.

Created with the built-in image generation tool on 2026-09-12. The PNG was
preserved unchanged; ICO variants are format conversions at standard sizes.

Generation prompt:

> Use case: logo-brand. Create one finished Windows application icon for AI Toolkit, a Stronghold Crusader castle/village editor. Reference image: the extracted original Village Editor icon; use it as the identity reference, not a background to preserve. Modernize its bold ivory AI lettering on a dark field and the strong horizontal foundation beneath it. Design a clean charcoal/dark-teal rounded-square badge with a crisp, chunky ivory geometric 'AI' monogram, a restrained warm amber foundation accent, and a subtle castle-battlement character incorporated in the A silhouette. Keep the letters immediately readable as AI, even at 24 pixels. Flat, precise vector-like raster artwork with only very subtle depth, large simple shapes, excellent contrast. One icon only, front-facing and centered, square 1024x1024 canvas with genuinely transparent space outside the rounded badge and about 8% breathing room. No mockup, no desktop, no extra words, no tiny ornaments, no gradients outside the badge, no drop shadow extending into the transparent margin. Preserve the original's compact, functional utility-icon identity rather than making a detailed castle illustration.
